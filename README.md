
# CampusNotes

CampusNotes is a student-focused note management application.

## Features

- Add notes
- View notes
- Search notes
- Edit notes
- Delete notes
- Save notes using JSON storage

## Technologies Used

- Python
- HTML
- CSS
- JavaScript
- JSON

## Project Structure

- main.py - Python application
- index.html - Web interface
- style.css - Web design
- script.js - Web functionality
- notes.json - Notes storage
- README.md - Documentation

## How to Run

Open Git Bash in the project directory and execute:

python main.py

## Project Purpose

CampusNotes helps students organize academic information and manage study notes efficiently.
- GitHub clone and remote synchronization verified.
